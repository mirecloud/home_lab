#  PostgreSQL Deployment — MireCloud Lab

This document summarizes the deployment and configuration of your **PostgreSQL instance** installed via the CloudPirates Helm chart, used as the external database for Keycloak.

---

##  PostgreSQL Deployment

PostgreSQL was installed with:

```bash
helm install postgres oci://registry-1.docker.io/cloudpirates/postgres -n postgres
```

Deployment result:

```
NAME: postgres
NAMESPACE: postgres
STATUS: deployed
REVISION: 1
```

---

##  Database Credentials (from Kubernetes Secret)

After deployment, the chart created a secret containing:

| Key | Value (decoded) |
|-----|------------------|
| **database** | postgres |
| **username** | postgres |
| **host** | postgres.postgres.svc |
| **port** | 5432 |
| **postgres-password** | 7lsoGvNqCuoqxVLxqL0hC0yL3WzQGQ26 |

>  **Password is auto‑generated by the chart and stored in the secret.**

To view the secret again:

```bash
kubectl -n postgres get secret postgres -o yaml
```

To decode a field:

```bash
echo 'N2xzb0d2TnFDdW9xeFZMeHFMMGhDMHlMM1d6UUdRMjY=' | base64 -d
```

##  Connection URI (decoded)

```
postgresql://postgres:7lsoGvNqCuoqxVLxqL0hC0yL3WzQGQ26@postgres.postgres.svc:5432/postgres
```

This URI is used by Keycloak for database persistence.

##  Test DB Connectivity From Inside the Cluster

Start a temporary pod:

```bash
kubectl run psql --rm -it --image=postgres:17 -- bash
```

Inside the pod:

```bash
psql "postgresql://postgres:7lsoGvNqCuoqxVLxqL0hC0yL3WzQGQ26@postgres.postgres.svc:5432/postgres"
```

You should land in the psql shell.

---

##  Notes

- This database is external and persistent across Keycloak redeployments.
- Only Keycloak should use this DB (avoid sharing the DB with other apps).
- If you reinstall Keycloak, **do NOT delete the Postgres secret or PVCs** unless you want a fresh database.

This PostgreSQL instance is fully compatible with your Keycloak Helm deployment.
